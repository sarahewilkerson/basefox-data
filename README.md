# basefox-data

The published dataset the Basefox app reads: `v1/dataset.json`, served by GitHub Pages.

Written by the weekly sweep in the (private) basefox repo, and only when a sweep passes its
quality gate. Do not edit by hand; a hand edit is overwritten by the next sweep.

The path is versioned. A breaking schema change publishes `v2/`, and installed builds keep
reading `v1/`.
